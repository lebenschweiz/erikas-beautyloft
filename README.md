# Erika's Beauty Loft

Website von Erika's Beauty Loft in Langwiesen bei Feuerthalen: dauerhafte Haarentfernung, Maniküre mit Gellack und Nageldesign.

Nachbau der bisherigen Wix-Seite als statische Seiten (HTML, CSS, JavaScript), ohne Build-Schritt. Läuft über GitHub Pages direkt aus dem Branch `main`.

Offen vor dem Livegang: Bestätigung der Bildrechte durch Erika, Impressum und Datenschutzerklärung.
